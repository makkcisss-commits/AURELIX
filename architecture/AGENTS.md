# Agents

Agents are replaceable workers, not authorities.

Initial roles:
- Research Agent
- Market Analyst
- Technology Analyst
- Opportunity Analyst
- Business Analyst
- Developer Agent
- QA Agent
- Security Agent
- Content Agent
- Marketing Agent
- Sales Agent
- Financial Analyst
- Auditor Agent
- Learning Agent

Every agent should declare:
- identity;
- purpose;
- allowed tools;
- data scope;
- autonomy tier;
- escalation conditions;
- expected outputs;
- audit requirements.

No agent may grant itself permissions.
