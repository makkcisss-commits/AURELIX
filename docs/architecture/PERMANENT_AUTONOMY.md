# Autonomie permanente — contrat opérationnel

## Boucle canonique

AURELIX fonctionne comme une seule boucle durable : observer, rechercher, produire des preuves, qualifier, gouverner, vérifier les capacités, exécuter uniquement les actions autorisées, enregistrer les résultats, distinguer estimation/résultat/revenu observé, apprendre et retester.

## Force opérationnelle

- capacité inconnue = blocage + lacune d'apprentissage ;
- connaissance candidate = non opérationnelle tant qu'elle n'est pas validée ;
- opportunité candidate = non commerciale tant qu'elle n'est pas qualifiée ;
- revenu estimé = jamais revenu observé ;
- permission absente = aucune exécution ;
- preuve insuffisante = recherche ou escalade ;
- erreur = diagnostic et récupération, jamais masquage.

## Déduplication

Une responsabilité possède une implémentation canonique. Les doublons certains peuvent être supprimés automatiquement ; les conflits ambigus sont signalés et bloqués.

## Preuve économique

Une opportunité n'est économiquement réalisée que lorsque le résultat et le revenu ont été observés par une source identifiable. Les simulations ne peuvent jamais être présentées comme revenus réels.
