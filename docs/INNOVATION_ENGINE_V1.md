# AURELIX Innovation Engine V1

Innovation converts accumulated Academy knowledge into bounded proposals for new products, services, workflows or internal capabilities.

```text
Academy knowledge
      ↓
Problem
      ↓
Proposed solution
      ↓
Expected value
      ↓
Cost + risk + confidence
      ↓
Priority score
      ↓
Governor
      ↓
Experiment / Build
```

## Guardrails

- Every proposal must reference existing Academy knowledge.
- The score is a prioritization aid, not authorization.
- Innovation proposals cannot spend money or change production.
- Any paid experiment remains behind Owner Approval, Execution Gate and Treasury.
- Production changes require a separate deployment/change-control boundary.
