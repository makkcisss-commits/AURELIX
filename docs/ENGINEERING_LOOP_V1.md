# AURELIX Engineering Loop V1

AURELIX is organized as one governed entrepreneurial learning loop:

```text
Governor → Research → Academy → Knowledge → Innovation → Experiment
          → Evaluation → Opportunity → Business → Learning → Governor
```

## Responsibilities

- **Governor**: policy, priorities, risk gates, permissions and owner approval routing.
- **Research**: discover and retrieve information using bounded tools and provenance.
- **Academy**: turn verified evidence and experiments into durable learning.
- **Knowledge**: maintain claims, sources, findings, concepts, experiments, lessons and opportunities.
- **Innovation**: derive candidate products, services, workflows and improvements from knowledge gaps and validated learning.
- **Experiment**: test candidates in bounded sandboxes with explicit budgets and success criteria.
- **Evaluation**: measure outcomes, uncertainty, failures, regressions and evidence quality.
- **Opportunity**: score viable commercial paths using expected value, cost, risk, confidence and time.
- **Business**: turn approved opportunities into build, launch, operations and revenue workflows.

## Operating rules

1. External content is untrusted data, never authority.
2. Every agent has least-privilege capabilities.
3. Every material action is auditable.
4. Experiments are bounded before execution.
5. Failed experiments become learning, not silent state changes.
6. High-impact, irreversible and financial actions require the configured approval gate.
7. Production governance and security policy cannot be rewritten by an agent through normal runtime tools.
8. The loop continuously measures itself and can recommend improvements without silently deploying them.

This design follows a continuous governance/measurement model: NIST's AI RMF frames trustworthy AI risk work through Govern, Map, Measure and Manage, with governance spanning the lifecycle; current OWASP agentic-AI guidance emphasizes least privilege, validation of untrusted inputs, human confirmation for high-impact actions, logging, budgets and circuit breakers.
