# AURELIX Learning + Academy V1

AURELIX now separates measured outcomes from curated knowledge.

```text
Experiment
   ↓
Measured outcome
   ↓
Learning
   ↓
Evidence + confidence
   ↓
Academy knowledge
   ↓
Future Research / Innovation
```

## Learning rules

- A learning must reference its experiment.
- A learning records an explicit outcome: success, failure or inconclusive.
- Observations are required.
- Evidence references are retained.
- Confidence is explicit and bounded from 0 to 1.

## Academy rules

- Knowledge must reference at least one learning.
- Source references can be retained alongside learning references.
- Knowledge is not treated as fact merely because it is stored.
- Confidence remains explicit.
- No learning can directly authorize spending or production changes.

This creates a traceable institutional-memory layer for the Research → Experiment → Learning → Academy → Research loop.
